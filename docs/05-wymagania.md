Dokumentacja analityczna LogViz: [01 Problem i zakres](01-problem-i-zakres.md) · [02 Proces](02-proces.md) ·
[03 User flow](03-user-flow.md) · [04 Model danych](04-model-danych.md) ·
**05 Wymagania** · [06 Decyzje](06-decyzje.md) · [07 Ograniczenia](07-ograniczenia.md)

Wymagania są wyprowadzone **z zaimplementowanego zachowania** (nie z planów). Kryterium akceptacji
zapisano w formie „Zakładając / Gdy / Wtedy”, tak aby dało się je sprawdzić testem. Kolumna „Gdzie
zrealizowane” podaje kod i — jeśli istnieje — moduł testu (`<app>.tests.<moduł>`).
Znak ⚠ oznacza, że implementacja ma znane ograniczenie opisane w [07](07-ograniczenia.md).
